Byte information for NPC table
Loc | Lnk | Plc | Plik | FP | Interac (2B) | (1B) | LP(2B) | (10B) | NPC Path (8B) | PWait (2B) | (2B) | Cwait(2B) | (5B/6B)

I believe, mathetmatically, the padding at the back is 6bytes, not 5, to match the table size of 40 bytes.

Loc = Current location (see Map section for byte values)*
Lnk = Entrance ID to the current location*
Plc = Previous location (see Map section for byte values)*
Plik = Exit ID of previous location*
FP = Friendship points
LP = Love Point
Interac = Interaction (did you talk to the NPC today, did you give it a gift…)
NPC Path = Path information
P Wait = Timer waiting for next action along path
C Wait = Waiting when character blocks them
* Only for Player Character (00 00 00 00 for everyone else)

Tools Experience gauge:
	Milker EXP: 0x23DDF30 (NA1.0) | 0x23DDED2 (EU 1.1)
	Shear EXP : 			0x23DDED0
Tools Level:
	Milker Level: 0x23DDEB4 (EU 1.1)
	Shear Level : 0x23DDEB5-B6

Little endian. The first byte of the experience gauge is the LSB. Second byte is MSB. 
LSB is incremented by 100 every time you use the tool. 0->100->200->0, after which MSB increments by one.
After MSB ticks over FF, the tool level increases by 1.

0x27E326C (EU1.1) is the ghost variable for where the Milker Level UI is displayed. Modifying has no effect.
223DDED3 000000FF or 123DDED2 0000FFFF are good for levelling after a couple of presses.

The actual memory for the milker level is at 0x23DDEB4, 2 bytes (not 1!)
	- When you level up one time, the game adds 4 to the LSB at 0x23DDEB4, making the max level (99) to be stored as 8E 01 (little endian)
	- Code for milker level 99 is this: 123DDEB4 0000018E
		- Note that you need to refresh the menu page for it to show as 99

Above hypothesis is wrong.
newly observed behaviour:
When the milker levels up, the byte at 0x23DDEB4 increments by 4. At level 64, it increments the byte at 0x23DDEB5 by 1.

As for the shear, when the shear levels up, it increments by 2. At shear level 99, 0x23DDEB5 value would be C6. But if milker level is >= 64, value would be C7.
